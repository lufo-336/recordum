# Milestone 3.6 — Journal Editor + Notes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a WebView2 + Toast UI markdown editor surface and full `Note` entity CRUD, with a tab switcher in `HabitScreen` (Completion | Notes) plus graceful degradation when the WebView2 Runtime is missing.

**Architecture:** Composition over inheritance. New `MarkdownEditorControl` UserControl wraps WebView2 + a vendored Toast UI bundle (no CDN), exposing `Markdown` as a TwoWay DependencyProperty. `NotesViewModel` is a master-detail host bound to a new `NotesTabView`. `INoteService` is fleshed out with the same EF + EventBus pattern used by `CompletionService` in M3.5. Zero schema delta — `Note` and `Attachment` tables already exist from `InitialSchema`.

**Tech Stack:** C# / .NET 10, WPF + CommunityToolkit.Mvvm, EF Core 9, Microsoft.Web.WebView2, Toast UI Editor (vendored JS).

**Spec:** `docs/superpowers/archive/specs/2026-05-22-milestone-3.6-journal-editor-design.md` is authoritative on conflicts with this plan.

- **Phase A — Core / Data (Tasks 1–7)** — `WellKnownEvents.NoteDeleted`, 3 payload records, `INoteService` flesh-out, `NoteService` impl with EventBus emit, DI registration, integration tests.

## Conventions

- TDD per task: failing test → minimal impl → pass → commit. Skip the test step only where the task is a pure XAML / NuGet / docs change (explicit in the task body).
- Commit message format: `<type>(<scope>): <subject>` — `feat`, `test`, `fix`, `refactor`, `docs`, `i18n`.
- Build must be zero-warning before each commit.
- All user-facing strings via `Strings.resx` (+ `.it.resx`); never literals in XAML or VM `ErrorMessage` constants.
- `IClock` for "now"; never `DateTime.UtcNow` / `.Now` directly.
- `ValueTask` for service methods, `Task` at the WPF/VM boundary.
- `CommunityToolkit.Mvvm` `[ObservableProperty]` / `[RelayCommand]` (`Save()` method → generated `SaveCommand`, not `SaveCommandCommand` — avoid naming traps from M3.5 lessons).
- Targeted test: `dotnet test --filter <expr>`. Full suite: `dotnet test`.

```csharp
using Recordum.Plugins.Contracts.Events;
using Recordum.Plugins.Contracts.Hosting;

namespace Recordum.Data.Services;

public sealed partial class NoteService(
    IDbContextFactory<RecordumDbContext> dbFactory,
    IClock clock,
    ILogger<NoteService> logger,
    IEventBus eventBus) : INoteService
{
    [LoggerMessage(EventId = 1, Level = LogLevel.Information, Message = "Note {Id} created for habit {HabitId}")]
    private partial void LogCreated(Guid id, Guid habitId);

    public async ValueTask<Guid> CreateAsync(Note draft, CancellationToken ct = default)
    {
        ArgumentNullException.ThrowIfNull(draft);
        if (draft.Id == Guid.Empty) draft.Id = Guid.NewGuid();
        if (draft.UpdatedAtMs == 0) draft.UpdatedAtMs = clock.UtcNowMs;

        await db.SaveChangesAsync(ct);
        LogCreated(draft.Id, draft.HabitNodeId);
        eventBus.Publish(new NoteCreatedPayload(draft.Id, draft.HabitNodeId));
        return draft.Id;
    }
```

```csharp
public async ValueTask UpdateAsync(Guid id, Action<Note> mutate, CancellationToken ct = default)
{
    ArgumentNullException.ThrowIfNull(mutate);
    await using var db = await dbFactory.CreateDbContextAsync(ct);
    var n = await db.Notes.FirstOrDefaultAsync(x => x.Id == id, ct);
    if (n is null) return;
    mutate(n);
    n.UpdatedAtMs = clock.UtcNowMs;
    await db.SaveChangesAsync(ct);
    eventBus.Publish(new NoteUpdatedPayload(n.Id, n.HabitNodeId));
}

public async ValueTask DeleteAsync(Guid id, CancellationToken ct = default)
{
    await using var db = await dbFactory.CreateDbContextAsync(ct);
    var n = await db.Notes.AsNoTracking().FirstOrDefaultAsync(x => x.Id == id, ct);
    if (n is null) return;
    await db.Notes.Where(x => x.Id == id).ExecuteDeleteAsync(ct);
    eventBus.Publish(new NoteDeletedPayload(n.Id, n.HabitNodeId));
}

public async ValueTask<Note?> GetAsync(Guid id, CancellationToken ct = default)
{
    await using var db = await dbFactory.CreateDbContextAsync(ct);
    return await db.Notes.AsNoTracking().FirstOrDefaultAsync(n => n.Id == id, ct);
}
```

```javascript
    const md = editor.getMarkdown();
    window.chrome.webview.postMessage({ type: 'change', md });
  });

  window.chrome.webview.addEventListener('message', (event) => {
    const data = event.data;
    if (!data || typeof data !== 'object') return;
    switch (data.type) {
      case 'setContent':
        if (editor.getMarkdown() !== data.md) {
          suppressNext = true;
          editor.setMarkdown(data.md || '');
        }
        break;
      case 'setReadOnly':
        // Toast UI doesn't have a true read-only mode; emulate by disabling input.
        document.querySelector('.toastui-editor-defaultUI').style.pointerEvents = data.value ? 'none' : '';
        break;
    }
  });

  // Signal ready so the .NET side can flush its initial setContent.
  window.chrome.webview.postMessage({ type: 'ready' });
})();
```

```csharp
using System.IO;

using System.Windows;
using System.Windows.Controls;
using Microsoft.Web.WebView2.Core;
using Recordum.WPF.Bootstrap;

namespace Recordum.WPF.Controls;

public partial class MarkdownEditorControl : UserControl
{
    private bool _bridgeReady;
    private bool _isDisposed;

    public static readonly DependencyProperty AvailabilityProperty =
        DependencyProperty.Register(nameof(Availability), typeof(IWebView2Availability), typeof(MarkdownEditorControl),
            new PropertyMetadata(null, (d, e) => ((MarkdownEditorControl)d).TryInitAsync()));
    public IWebView2Availability? Availability
    {
        get => (IWebView2Availability?)GetValue(AvailabilityProperty);
        set => SetValue(AvailabilityProperty, value);
    }

    // (existing DPs unchanged; add OnMarkdownChanged callback hook below)

    public MarkdownEditorControl()
    {
        InitializeComponent();
        Loaded += async (_, _) => await TryInitAsync();
        Unloaded += (_, _) => _isDisposed = true;
    }

    private async Task TryInitAsync()
    {
        if (_isDisposed) return;
        if (Availability is not { IsAvailable: true, Environment: not null } a) return;
        if (WebView.CoreWebView2 is not null) return; // already inited

        await WebView.EnsureCoreWebView2Async(a.Environment);
        var assetsRoot = Path.Combine(AppContext.BaseDirectory, "Resources", "EditorAssets");
        WebView.CoreWebView2.SetVirtualHostNameToFolderMapping(
            "recordum.local",
            assetsRoot,
            CoreWebView2HostResourceAccessKind.Allow);
        WebView.CoreWebView2.WebMessageReceived += OnWebMessageReceived;
        WebView.CoreWebView2.Navigate("https://recordum.local/editor.html");
    }

    private void OnWebMessageReceived(object? sender, CoreWebView2WebMessageReceivedEventArgs e)
    {
        if (_isDisposed) return;
        try
        {
            using var doc = JsonDocument.Parse(e.WebMessageAsJson);
            var root = doc.RootElement;
            var type = root.GetProperty("type").GetString();
            switch (type)
            {
                case "ready":
                    _bridgeReady = true;
                    PushContentToEditor(Markdown);
                    PushReadOnlyToEditor(IsReadOnly);
                    break;
                case "change":
                    var md = root.GetProperty("md").GetString() ?? string.Empty;
                    if (Markdown != md) SetCurrentValue(MarkdownProperty, md);
                    break;
            }
        }
        catch (JsonException) { /* malformed JS message — ignore */ }
    }

    private void PushContentToEditor(string md)
    {
        if (!_bridgeReady || _isDisposed || WebView.CoreWebView2 is null) return;
        var payload = JsonSerializer.Serialize(new { type = "setContent", md });
        WebView.CoreWebView2.PostWebMessageAsJson(payload);
    }

    private void PushReadOnlyToEditor(bool value)
    {
        if (!_bridgeReady || _isDisposed || WebView.CoreWebView2 is null) return;
        var payload = JsonSerializer.Serialize(new { type = "setReadOnly", value });
        WebView.CoreWebView2.PostWebMessageAsJson(payload);
    }
}
```

## Known risks

- **WebView2 SDK paths**: `Microsoft.Web.WebView2.Wpf` references must match the same package version used by `Microsoft.Web.WebView2`. Task 8 pins `1.0.*`; the WPF assembly comes from the same package.
- **Toast UI bundle license**: MIT — vendoring is permitted. Confirm by reading `LICENSE` in the downloaded bundle before commit; copy alongside the JS/CSS files (`Resources/EditorAssets/LICENSE-toast-ui.md`).
- **`SetVirtualHostNameToFolderMapping` path on test runners**: the assets path is resolved relative to `AppContext.BaseDirectory`. For unit tests that don't host the UserControl, the test still passes (no init triggered). For the integration smoke tests, they don't open the control either. Manual smoke remains the validation surface.
- **WPF DataTemplate re-instantiation**: switching between `Completion` and `Notes` tabs while the editor has unsaved edits → switching back rebuilds the editor and re-runs `setContent`. The JS bridge guards against ping-pong; no data loss because `EditorMarkdown` is held by `NotesViewModel`, not by the WebView2 instance.
- **`Microsoft.Web.WebView2.Wpf` thread affinity**: must be on the UI thread. All `Markdown` setters from VM happen on the UI thread (DataBinding marshals); no `await` posts a continuation off-thread inside the control. Verified by inspection.
