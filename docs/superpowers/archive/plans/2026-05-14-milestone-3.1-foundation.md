# Milestone 3.1 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Get Recordum to a state where the WPF app launches, creates a fully-schema'd SQLite DB on first run (including v2.3 provenance delta and full seed data), and initializes the plugin host skeleton — with tests covering schema, seed, interceptor and plugin components.

**Architecture:** Five .NET 10 projects (`Recordum.Core`, `Recordum.Data`, `Recordum.Plugins.Contracts`, `Recordum.Plugins`, `Recordum.WPF`) plus three test projects (xUnit). EF Core 9+ over SQLite with snake_case naming convention via `EFCore.NamingConventions`. Manual `ServiceCollection` DI in `App.xaml.cs`. Plugin host is `InProcessPluginHost` with `AlwaysAllowPermissionBroker` — no WebView2 sandbox in this milestone (Fase 7). No SQLCipher in this milestone (Milestone 3.2).

**Tech Stack:**
- .NET 10 / C# 13
- WPF (Windows desktop)
- EF Core 9+ with `Microsoft.EntityFrameworkCore.Sqlite` and `EFCore.NamingConventions`
- `CommunityToolkit.Mvvm` (added but not yet used; minimal use will start in Milestone 3.3)
- `Microsoft.Extensions.DependencyInjection`, `Microsoft.Extensions.Configuration.Json`, `Microsoft.Extensions.Logging`
- xUnit + `Microsoft.EntityFrameworkCore.InMemory` (we will NOT use this — schema tests use real SQLite in temp file) + `FluentAssertions`

`src/Recordum.Core/Abstractions/AmbientPluginContext.cs`:
```csharp
namespace Recordum.Core.Abstractions;

public sealed class AmbientPluginContext : IPluginContext
{
    private static readonly AsyncLocal<string?> Current = new();

    public string? PluginId => Current.Value;

    public IDisposable BeginScope(string pluginId)
    {
        ArgumentException.ThrowIfNullOrWhiteSpace(pluginId);
        var previous = Current.Value;
        Current.Value = pluginId;
        return new Scope(previous);
    }

    private sealed class Scope : IDisposable
    {
        private readonly string? _previous;
        private bool _disposed;

        public Scope(string? previous) => _previous = previous;

        public void Dispose()
        {
            if (_disposed) return;
            Current.Value = _previous;
            _disposed = true;
        }
    }
}
```

```csharp
using System.Reflection;
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.ChangeTracking;
using Microsoft.EntityFrameworkCore.Diagnostics;
using Recordum.Core.Abstractions;

namespace Recordum.Data.Interceptors;

public sealed class TimestampInterceptor(IClock clock, IPluginContext pluginContext) : SaveChangesInterceptor
{
    private static readonly HashSet<string> ProvenanceTypes =
        ["HabitNode", "HabitTemplate", "ExportTemplate", "Chart"];

    public override InterceptionResult<int> SavingChanges(DbContextEventData eventData, InterceptionResult<int> result)
    {
        Apply(eventData.Context);
        return base.SavingChanges(eventData, result);
    }

    public override ValueTask<InterceptionResult<int>> SavingChangesAsync(DbContextEventData eventData, InterceptionResult<int> result, CancellationToken cancellationToken = default)
    {
        Apply(eventData.Context);
        return base.SavingChangesAsync(eventData, result, cancellationToken);
    }

    private void Apply(DbContext? db)
    {
        if (db is null) return;

        var nowDt = clock.UtcNow.UtcDateTime;
        var nowMs = clock.UtcNowMs;
        var pluginId = pluginContext.PluginId;

        foreach (var entry in db.ChangeTracker.Entries())
        {
            if (entry.State is not (EntityState.Added or EntityState.Modified)) continue;

            var typeName = entry.Entity.GetType().Name;

            if (entry.State == EntityState.Added)
            {
                TrySet(entry, "CreatedAt", nowDt);
                if (pluginId is not null && ProvenanceTypes.Contains(typeName) && Get(entry, "CreatedByPluginId") is null)
                {
                    TrySet(entry, "CreatedByPluginId", pluginId);
                }
            }

            TrySet(entry, "UpdatedAt", nowDt);
            TrySet(entry, "UpdatedAtMs", nowMs);
        }
    }

    private static void TrySet(EntityEntry entry, string propertyName, object value)
    {
        var prop = entry.Metadata.FindProperty(propertyName);
        if (prop is null) return;
        entry.Property(propertyName).CurrentValue = value;
    }

    private static object? Get(EntityEntry entry, string propertyName)
    {
        var prop = entry.Metadata.FindProperty(propertyName);
        return prop is null ? null : entry.Property(propertyName).CurrentValue;
    }
}
```
