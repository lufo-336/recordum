Recordum — tre modelli per la Home

Mockup interattivo (tema scuro reale). Usa i pulsanti sotto ogni modello per simulare: apertura di un habit, ritorno a vuoto, e collasso/espansione. Il pannello ✎ Diario compare quando apri l'abitudine journal "Daily journal".

Modello A

Auto: piena ↔ sidebar

Niente aperto → Home riempie. Apri un habit → Home si stringe a sidebar. Il tasto ⌂ collassa/espande.
Prova: Stato: Home piena
⌂ sul rail sinistro = collassa la sidebar a 0 (Home torna piena se non c'è tab; resta solo il workspace se un tab è aperto). Deselezionare riporta sempre la Home piena → niente più spazio nero.
Modello B

Home sempre sidebar fissa

La Home è sempre una colonna stretta a sinistra. Il workspace mostra la Panoramica o un habit. ☰ collassa la sidebar.
Prova: Stato: Panoramica
La sidebar non sparisce mai (salvo collasso esplicito ☰). Lo spazio a destra è sempre il workspace: una "Panoramica" di default quando nessun habit è aperto (non più area nera).
Modello C

Solo fix, modello attuale

Comportamento di oggi (piena↔sidebar) ma reso affidabile: deselezionare riporta Home piena, niente larghezza sidebar "incastrata".
Prova: Stato: Home piena
Nessun nuovo affordance: solo il fix dello spazio nero (deselezione → Home piena) + reset della larghezza sidebar persistita + i 2 crash del log.
