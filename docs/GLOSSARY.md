# Glossario

Le parole dell'interfaccia, in inglese e in italiano. La guardia è `GlossaryGuardTests`: una parola vietata nuova si
aggiunge lì. Sono tutte decisioni dell'autore: quelle della spec
`2026-11-10-v1-ux-review-and-path-design.md` §6.4 e, dal 2026-11-12, le parole che le `.resx` usavano già (erano marcate
come proposte).

| inglese | italiano | cosa vuol dire | non si scrive |
|---|---|---|---|
| action | azione | tipo: una cosa fatta o non fatta nel giorno | |
| counter | contatore | tipo: una o più misure (quantità, tempo, scala) | |
| abstinence | astinenza | tipo: il tempo da quando si è smesso | resistenza, resistance |
| journal | diario | tipo: testo scritto nel giorno | journal (in italiano) |
| state | stato | tipo: un valore che dura finché non lo si cambia | |
| group | gruppo | abitudini composte insieme | |
| streak | di fila | giorni consecutivi riusciti: "3 giorni di fila" | streak, serie (in italiano) |
| current streak | di fila ora | i giorni di fila in corso | serie attuale |
| best streak | record di fila | il massimo raggiunto: "record: 12" | serie migliore |
| goal streak | obiettivi di fila | obiettivi raggiunti uno dopo l'altro | serie obiettivo |
| streak (in Configure) | Giorni di fila | la riga di Configura e il conteggio ("Conteggio dei giorni di fila") | Modalità streak |
| sets | serie | unità della palestra: "3 serie da 10" | serie per lo streak |
| series (chart) | serie | una linea o un gruppo di barre in un grafico | |
| records | registrazioni | più registrazioni nello stesso giorno | nomi delle serie |
| relapse | ricaduta | la fine di un periodo di astinenza: "Ricaduta il 16 ott" | lapse, ho ceduto, gave in |
| Log a relapse… | Segna una ricaduta… | il comando che chiude il periodo in corso | Ho ceduto…, I gave in… |
| relapses in 90 d | ricadute in 90 g | quante ricadute negli ultimi 90 giorni | tentativi, attempts |
| free | libero | "Libero da", "giorni liberi": il tempo senza ricadute | pulito, clean |
| Recorded with | Si registra con | il gesto con cui si registra un'abitudine | Gesto primario, Primary gesture |
| unit next to a value | unità accanto al valore | il simbolo se c'è ("2 h", "20 min"), altrimenti il nome ("12 pagine") | 2 hours |
| entry | voce | un testo in un diario | nota (per i diari) |
| note | nota | un testo accanto a un'abitudine che non è un diario | voce (fuori dai diari) |
| record | registrazione | un evento salvato: una spunta, un valore, un periodo | |
| day | giorno | il giorno dell'abitudine, dal suo inizio della giornata | |
| day start | inizio della giornata | l'ora in cui comincia il giorno (`daily_reset_time`) | |
| goal | obiettivo | il traguardo di un periodo | |
| schedule | programma | i giorni in cui l'abitudine è prevista | Tipo di pianificazione |
| template | modello | una composizione salvata da cui creare un'abitudine | |
| column | colonna | un riquadro della schermata dell'abitudine | |
| Log | Cronologia | la colonna con l'elenco delle registrazioni | |
| Detail | Dettaglio | la scheda con cifre e grafici dell'abitudine | |
| Configure | Configura | la scheda dove si cambia l'abitudine | |
| archive | archivio | abitudini messe da parte, con il loro storico | |
| trash | cestino | abitudini eliminate, ancora recuperabili | |
| backup | backup | il file cifrato `.recbak` | |
| restore | ripristino | riportare i dati da un backup | |
| passphrase | passphrase | la frase che protegge dati e backup; persa quella, persi i dati | |
| mark | scaglione | un valore intero della scala con un nome (e il suo tag): "Bene" a 4. Senza nome è una tacca | gradino, step, etichetta (per un valore di scala) |
