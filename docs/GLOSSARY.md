# Glossario

Le parole dell'interfaccia, in inglese e in italiano. La guardia è `GlossaryGuardTests`: una parola vietata nuova si
aggiunge lì. Le righe senza "(proposta)" sono decisioni dell'autore (spec `2026-11-10-v1-ux-review-and-path-design.md`
§6.4); quelle con "(proposta)" sono le parole che le `.resx` usano oggi, da confermare.

| inglese | italiano | cosa vuol dire | non si scrive |
|---|---|---|---|
| action | azione (proposta) | tipo: una cosa fatta o non fatta nel giorno | |
| counter | contatore (proposta) | tipo: una o più misure (quantità, tempo, scala) | |
| abstinence | astinenza | tipo: il tempo da quando si è smesso | resistenza, resistance |
| journal | diario | tipo: testo scritto nel giorno | journal (in italiano) |
| state | stato (proposta) | tipo: un valore che dura finché non lo si cambia | |
| group | gruppo (proposta) | abitudini composte insieme | |
| streak | di fila | giorni consecutivi riusciti: "3 giorni di fila" | streak, serie (in italiano) |
| current streak | di fila ora (proposta) | i giorni di fila in corso | serie attuale |
| best streak | record di fila (proposta) | il massimo raggiunto: "record: 12" | serie migliore |
| goal streak | obiettivi di fila (proposta) | obiettivi raggiunti uno dopo l'altro | serie obiettivo |
| streak (in Configure) | Giorni di fila | la riga di Configura e il conteggio ("Conteggio dei giorni di fila", proposta) | Modalità streak |
| sets | serie | unità della palestra: "3 serie da 10" | serie per lo streak |
| series (chart) | serie (proposta) | una linea o un gruppo di barre in un grafico | |
| records | registrazioni | più registrazioni nello stesso giorno | nomi delle serie |
| relapse | ricaduta | la fine di un periodo di astinenza: "Ricaduta il 16 ott" | lapse (proposta), ho ceduto, gave in |

| relapses in 90 d | ricadute in 90 g | quante ricadute negli ultimi 90 giorni | tentativi, attempts |

| unit next to a value | unità accanto al valore | il simbolo se c'è ("2 h", "20 min"), altrimenti il nome ("12 pagine") | 2 hours |

| note | nota | un testo accanto a un'abitudine che non è un diario | voce (fuori dai diari) |
| record | registrazione (proposta) | un evento salvato: una spunta, un valore, un periodo | |
| day | giorno (proposta) | il giorno dell'abitudine, dal suo inizio della giornata | |
| day start | inizio della giornata (proposta) | l'ora in cui comincia il giorno (`daily_reset_time`) | |

| schedule | programma (proposta) | i giorni in cui l'abitudine è prevista | Tipo di pianificazione |
| template | modello (proposta) | una composizione salvata da cui creare un'abitudine | |
| column | colonna (proposta) | un riquadro della schermata dell'abitudine | |
| Log | Cronologia (proposta) | la colonna con l'elenco delle registrazioni | |
| Detail | Dettaglio (proposta) | la scheda con cifre e grafici dell'abitudine | |
| Configure | Configura (proposta) | la scheda dove si cambia l'abitudine | |
| archive | archivio (proposta) | abitudini messe da parte, con il loro storico | |
| trash | cestino (proposta) | abitudini eliminate, ancora recuperabili | |
